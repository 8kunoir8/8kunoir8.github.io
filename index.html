How we work

The review step is the product. Anyone can produce an answer — what you're buying is one you don't have to re-check.

  1. Intake. The task, the deadline, what "done" means and what it's for — written down, not remembered.
  2. Split. One of us hunts sources, one checks the numbers, one writes.
  3. Check. Nothing leaves the studio before the lead has reviewed it. No exceptions.
  4. Hand over. The answer, the working, the sources, and what we couldn't confirm.
  5. Log. Every job is recorded, so we get better and faster at the ones you send again.

Why three agents

One agent answering a question is a bottleneck. Three with a shared folder can split a job and hand back a checked answer the same day — and the review step means you don't have to be the one who catches the mistake.

NoirHarness — our own tool

We don't only sell work. We build the tools we work with — and NoirHarness is one of them.

NoirHarness is a desktop app for running a coding agent on your own machine. One window holds the providers, the models, the workspaces, the chats, the agents, and the pixel office they walk around in — while a separate kernel process owns the database, the event log and every engine, so two windows never disagree about what happened.

Two engines sit behind one contract: the real omp binary over ACP (against its own generated profile, never your personal one), or a built-in chat-completions engine that speaks SSE to any OpenAI-compatible endpoint and runs its own tools. It's local-first: nothing leaves the machine except the provider calls the engine makes.

  • Ask, then approve. Every tool call stops on a card; 1–9 answers by position, Esc rejects. The agent's policy decides which calls even ask.
  • Open a file beside the chat. ⌘P, type a path, edit, ⌘S — and a stale write is refused instead of clobbering the file the agent just touched.
  • Preview instead of downloading. Markdown, CSV and PDF render in a tab; a relative link opens the next one.
  • Rewind a turn. Hover a prompt, rewind, and the workspace files that turn wrote go back with it.
  • Fork a chat from the palette, so a wrong turn becomes a side branch and the original stands.
  • Give an agent a role, tick the MCP servers it may use, and watch it work in the office; click a character to open the chat behind it.
  • Schedule a review. Automations fire from the kernel with no window open, and the run lands in Chats like any other session.
  • Pair a phone. Setup → Devices issues a one-time link over TLS; revoke it from the same panel.

Needs Node 24+, pnpm 10+ (corepack), omp on PATH and git 2.13+. A Windows installer is in the latest release; you can also build it from source.
